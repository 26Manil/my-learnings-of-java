# Object-Oriented Programming

A collection of my **Java OOP learning and practice**. This folder contains the programs and experiments I write while learning how to work with objects, classes, and object-oriented design in Java.

## Goal

The goal is to build a strong foundation in Java OOP and develop the ability to design programs using **clean classes, reusable code, meaningful relationships, and proper abstraction**.

This folder represents my progress from understanding the fundamentals to being able to apply OOP naturally while building Java programs.
