## 🌱 About This Repository

This repository is a personal record of my journey of learning Java programming. 
It documents my progress, practice, and growth as I explore this language step by step through an online course.

---

## ✨ Purpose

Java is the language I have chosen to begin my journey into programming, and this repository is where that journey lives.
It focuses on building a solid understanding of the basics of Java along with Object-Oriented Programming (OOP), 
which together form the foundation of the language.

The main purpose of this repository is to:

> 📚 Keep a clear and organized record of my progress as I learn the basic concepts of Java and Object-Oriented Programming.

> 💻 Practice consistently by turning what I learn into actual code, not just notes.

> 🔍 Track how my understanding of Java fundamentals and OOP develops over time, one concept and one project at a time.

> 🧱 Build a strong foundation in Java basics and OOP that supports further learning in the future.
